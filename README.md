# README 
Módulo II. Modelos Estadisticos

Descripción

Este repositorio contiene la documentación, ejercicios y actividades desarrolladas durante el Módulo II del Diplomado en Técnicas Estadísticas.

Su propósito es recopilar y organizar el trabajo realizado a lo largo del módulo, utilizando notebooks de Jupyter como medio para documentar los procedimientos, aplicar los conceptos estadísticos estudiados y presentar los resultados obtenidos en los distintos ejercicios.

Contenido del repositorio

Los archivos se encuentran organizados en notebooks (".ipynb"), que incluyen:

- Documentación: apuntes, conceptos y explicaciones de los temas abordados durante las sesiones.
- Ejercicios prácticos: resolución de problemas y actividades relacionadas con los contenidos del módulo.
- Implementaciones: desarrollo de procedimientos estadísticos mediante código Python.
- Resultados y análisis: salidas, interpretaciones y observaciones derivadas de los ejercicios realizados.

Herramientas utilizadas

- Python
- Jupyter Notebook
- Bibliotecas de análisis y procesamiento de datos de Python.

Organización

Los notebooks se incorporan al repositorio conforme se desarrollan las actividades del módulo, permitiendo mantener un registro del aprendizaje y del trabajo realizado.

Propósito académico

Este repositorio constituye una evidencia del trabajo y las actividades realizadas durante el Módulo II del Diplomado en Técnicas Estadísticas, así como un espacio de consulta y seguimiento de los contenidos abordados.
